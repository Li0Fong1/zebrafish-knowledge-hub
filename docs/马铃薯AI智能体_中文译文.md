# 面向马铃薯功能基因组学的 AI 知识中枢

尊敬的编辑：

马铃薯是最重要的块茎作物之一，全球约有 **13 亿**人以此为食。功能基因研究是提升作物产量、品质，以及应对快速变化全球气候抗性的基础（Wang et al., 2025）。近年来，马铃薯功能基因组学取得显著进展（Deng et al., 2024; Plunkert et al., 2024; Lian et al., 2025）。然而，马铃薯参考基因组（DM1-3 516 R44）的迭代更新引入了互不兼容的基因命名体系，使历史研究中基因 ID 与符号的对应一直困难（补充图 1）。与此同时，过去十年相关论文数量约增长 **100%**，已远超传统文献挖掘方法的处理能力（补充图 2）。这些问题共同阻碍了马铃薯功能基因组学的推进。

大语言模型（LLM）的出现，是处理艾字节级异构数据的范式转变（Yang et al., 2025; Zhang et al., 2025）。在此基础上，AI 智能体系统进一步把 LLM 的能力从认知辅助（“知道怎么做”）扩展到操作自主（“把事做成”），为生物学各领域中数据密集型难题带来变革性机会。

为利用 LLM 与 AI 智能体推动马铃薯研究，并展示其在功能基因组学中的潜力，我们构建了**马铃薯知识中枢（Potato Knowledge Hub）**（[https://www.potato-ai.top](https://www.potato-ai.top)；图 1）。该平台面向马铃薯研究社区免费开放，包含三大模块：

1. **基于检索增强生成（RAG）的马铃薯知识库**：汇聚 **6112** 篇高质量马铃薯研究文献，缓解通用 LLM 知识静态、易幻觉等问题，提供更准确的科学回答；
2. **人工策展的功能基因数据库**：基于最新马铃薯基因组组装，收录 **2853** 个已报道功能基因，并支持跨版本 ID 映射；
3. **实用工具集**：包含 BLAST、ID 转换、基因注释，以及 GO / KEGG 富集分析等，便于高效数据处理。

此外，我们开发了**马铃薯科研助手（Potato Research Assistant）**——一个整合上述全部模块的 AI 智能体，支持自然语言交互。马铃薯知识中枢旨在简化使用体验，把研究者从繁重的文献挖掘与碎片化分析流程中解放出来，提升个人研究效率，从而加速马铃薯功能基因组学领域的发现。

## 语料构建

构建马铃薯知识中枢的第一步，是建立高质量、专业化的马铃薯研究语料。为全面覆盖相关文献，我们在 NCBI PubMed 与 Web of Science Core Collection 中，以标题或摘要含 “potato” 为关键词检索，时间跨度为 **1900 年 1 月 1 日至今**，获得 **57 795** 篇以上非冗余论文（补充图 2）。

为富集高质量研究，我们参考中国科学院期刊分区，抽取生物学、农林科学及综合性学科中 **Q1、Q2** 期刊上的研究论文，得到 **21 505** 篇。随后用 LLM 分析标题与摘要，剔除仅提及 “potato”、但并未以马铃薯为研究对象的文献，筛得与马铃薯育种、遗传、代谢、生理、基因组及功能基因研究相关的 **6007** 篇。我们又人工审阅缺少摘要信息的 report / letter 类文章，补入 **105** 篇。为评估覆盖度，人工核对了马铃薯功能基因领域最近 **100** 篇文献，确认均已纳入。最终共收集 **6112** 篇高质量马铃薯研究论文。

为保证内容详尽准确，我们下载了全文 PDF，而非仅依赖摘要。每份 PDF 转为纯文本，供下游处理（补充图 3）。

## RAG 知识库

用 LLM 分析每篇论文的段落，剔除作者信息、单位、参考文献、致谢等非科学正文。采用 RAG 架构提升回答准确性、降低幻觉。全文经切分后，用嵌入模型向量化。为支持多轮对话，LLM 结合会话上下文分析用户问题并改写，以提高检索效率。改写后的问题用同一模型向量化，按嵌入距离检索最相关的前 **200** 个段落；再用重排序模型对每个片段与问题的语义相关性重新打分；将排名最高的片段与用户问题一并提交给 LLM，生成最终答案（补充图 4A、4B）。

> 为确定最优切分与检索设置，我们评估了三种切分方式（100 词、重叠 60 词；200 词、重叠 120 词；按自然段切分）与三种检索深度（重排序后 top 5、10、20）。收集了由教授、博士后与研究生提供的 **70** 道马铃薯知识题及已验证答案，并用 “LLM as a judge” 框架评估（Zheng et al., 2023）：由第三方模型 GPT-o3 从四维打分——知识准确性（40 分）、完整性（30 分）、相关性（20 分）、清晰度（10 分）。

结果表明，**按自然段切分**得分更高且更集中；固定长度切分在各检索深度下得分更分散，尽管 200 词切分与自然段切分差异不显著。在自然段切分下，仅取 top 5 时部分题目因参考内容不足而答不完整，得分低于 70；取 top 10 或 top 20 时得分分布高度相似（补充图 4C）。因此最终采用：**按自然段切分 + 检索 top 10 片段** 再交由 LLM 生成答案。该策展语料结合 RAG，可给出精准、领域专属的回答，幻觉风险较低（图 1B、1C；补充图 5）。

## 功能基因数据库与工具

持续更新的马铃薯参考基因组，以及互不兼容的基因命名体系，使历史研究中基因 ID 与符号难以统一（Potato Genome Sequencing Consortium et al., 2011; Pham et al., 2020; Yang et al., 2023）（补充图 1）。为此，我们建立了 **LLM 驱动的基因实体归一化流程**，将已报道基因准确映射到最新组装 **DMv8.1**。由 LLM 分析每篇全文纯文本，抽取已报道功能基因符号及对应 ID；用不同 LLM 独立抽取两轮以尽量提高覆盖，合并后人工策展，得到 **4947** 对基因 ID–符号。这些 ID 来自 GenBank、UniProt、Solanaceae Genomics Network、ATL_v3、SolTub3.0、DMv4.03、DMv6.1、DMv8.1 等多个数据库与基因组版本。全部标识符通过基因组共线性与基于 BLAST 的序列一致性映射到 DMv8.1，最终得到 **2853** 个非冗余功能基因（补充图 6A）。人工策展中还发现并纠正了历史命名错误（例如将 SP5G-B 误标为 SP6A；Herrera-Isidron et al., 2024），更正均有注释且可追溯。数据库保留 DMv8.1 基因 ID、历史标识符与来源文献中基因符号之间的直接链接，保证透明可查。

为增强研究可用性，每个基因条目还整合了 InterPro 结构域、UniProt 相似性信息与表达模式等关键功能注释（图 1B；补充图 6B）。另开发工具集：BLAST、Annotator、ID 转换器，以及 GO / KEGG 富集工具，支持快速 BLAST、结构域与符号注释、DMv4 / DMv6 到 DMv8 的 ID 转换，以及功能富集分析（补充图 7）。该基因数据库使研究者可用现行基因符号或历史标识符检索完整基因信息及相关文献，显著简化功能基因研究的背景调研，便于快速立项。

## 马铃薯科研助手（AI 智能体）

为优化与马铃薯知识中枢的交互，我们实现了**智能体任务编排架构**，并开发 **Potato Research Assistant**：可调用知识库、基因库与集成工具工作流的 AI 智能体（图 1A）。该智能体以自然语言与用户交互，进行意图分析，并调用相应内部脚本：汇总马铃薯研究知识、检索基因信息与序列、执行特定分析工具。对查询到的基因符号，助手可总结历史研究、提取序列（编码区、蛋白、自定义启动子区域等），并给出推定功能的详细信息。通过整合这些能力，AI 智能体把用户从繁琐文献挖掘与复杂生信软件中解放出来，使不具备专业计算背景的科学家也能高效探索与利用海量基因信息。

## 性能评估

除用于知识库评测的 70 题外，另收集 **20** 道基因理解题与 **10** 道序列提取题，以评估基因数据库。将马铃薯科研助手的回答与先进通用 LLM 对比：开源模型 DeepSeek-R1-0528、Qwen3-235B-A22B（开启思考），以及闭源模型 Gemini 2.5 Pro Preview-0506、Claude Sonnet 4。打分体系与前述 RAG 评估相同。

马铃薯科研助手在全部三类任务上均优于通用 LLM，体现了智能体任务编排架构与专用数据库设计，在领域专家知识掌握上优于通用模型。知识检索任务中，助手表现更稳定，通用 LLM 得分更两极分化，可能因其训练语料不完整（图 1C；补充图 5）。在基因详情理解与序列提取上，助手依托专用马铃薯基因库优势明显（图 1D、1E；补充图 8、9）。

---



## 结语

本工作针对马铃薯功能基因组学研究中的关键挑战——这也是遗传复杂度高、基因组版本不一致常见的作物研究的代表问题。马铃薯知识中枢将**按月更新**，纳入最新研究进展。我们期望该中枢成为推进马铃薯功能基因组学、支撑育种的重要社区资源。其中 LLM 驱动的基因实体归一化流程与智能体任务编排架构，也可迁移到其他生物学领域，用于构建类似平台。
