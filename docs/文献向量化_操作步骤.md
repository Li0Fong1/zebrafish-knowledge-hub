# 文献向量化 — 操作步骤（按当前进度）

> 适用：本仓库一期「是」文献 → 语料 JSONL → BGE 嵌入 → FAISS 检索  
> 当前源：优先 `pubmed_judgement_是.csv`；没有则用 `解析文件/已存在表.csv`（约 5577 有 PMID）  
> 详细说明见：`docs/文献向量化_技术推进指导手册.md`

## 开工前确认

在项目根目录打开 PowerShell：

```powershell
cd d:\PycharmProjects\斑马鱼基因问答体
$env:FAISS_DISABLE_AVX2 = "1"

# 1) 模型在不在
dir models\bge-small-zh-v1.5

# 2) 文献源能不能数出 PMID（必须 >0）
python -c "from rag.pubmed_yes_source import count_pubmed_yes_pmids; print(count_pubmed_yes_pmids())"
```

金标战役若在跑，保持**安静模式**即可，别开满速抢机器。

---

## 步骤 1：拉语料（先试 50 篇）

```powershell
python -m scripts.fetch_pubmed_yes_corpus --resume --limit 50
```

**过关标准：** 出现 `data/literature/pubmed_yes_corpus.jsonl`，抽几行 PMID、标题/摘要不是空的。

试通后再拉全量（一期先只要摘要，更快）：

```powershell
python -m scripts.fetch_pubmed_yes_corpus --resume --skip-fulltext
```

---

## 步骤 2：向量化（先嵌 100 篇）

```powershell
python -m scripts.vectorize_pubmed_judgement_yes --phase embed --resume --limit 100
```

**过关标准：**  
`%LOCALAPPDATA%\ZebrafishGeneQA\faiss_pubmed_yes\` 下有 `shard_0000`、`manifest.json`。

## 出问题怎么看

| 现象 | 先查 |
|------|------|
| PMID 数是 0 | `解析文件/已存在表.csv` 是否在；或补 `项目阶段/05_数据与库/归档/data_export/pubmed_judgement_full/pubmed_judgement_是.csv` |
| 语料文件没有 | 看 `data/literature/pubmed_yes_fetch.json`、网络/NCBI 限流 |
| 嵌入报错 / FAISS 崩 | 保持 `FAISS_DISABLE_AVX2=1`；磁盘是否够 |
| 搜索结果空 | 是否跑过 embed；路径是否指向 `faiss_pubmed_yes` |
