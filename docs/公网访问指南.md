# 公网访问指南

## 方式一：本机临时公网（推荐先试）

适合：给同事/审稿人 **短期试用**，无需买服务器、无需公网 IP。

1. 确保 MySQL 已启动，本机菜单 **2** 能正常打开 Web
2. 运行 **启动.bat → 16. 公网访问（临时隧道）**
   - 若 **2 已在运行**：16 会检测到 8080 已有 Web，**只开隧道**，不再重复启动（避免端口冲突）
   - 若 **2 未运行**：16 会自动启动 Web + 隧道
3. 或双击：`scripts\expose_internet.bat`
4. 等待出现类似：

   ```
   公网地址（发给他人）：https://xxxx.trycloudflare.com
   ```

5. 把该 **https 链接** 发给对方即可；**关闭窗口即停止访问**

注意：

- 每次启动链接可能变化
- **无登录密码**，勿长期公开
- 你电脑需保持开机、联网
- **公网模式已启用访问令牌 + 限流**（见下方「网络安全」）

### 网络安全（菜单 16 自动启用）

| 机制 | 说明 |
|------|------|
| **访问令牌** | 首次公网启动时自动生成，保存在 `logs/web_access_token.txt` |
| **严格模式 `WEB_STRICT=1`** | CSP 响应头、禁止 URL 传令牌；**上传仍可用**（走文件过滤） |
| **限流** | 对话 12/min；工具 30/min；上传 5/min；总 API 80/min |
| **暴力封禁** | 错误令牌 25 次 → IP 封禁 15 分钟 |
| **路径防护** | 拦截 `../`、`.env`、`.git` 等可疑路径 |
| **请求体上限** | JSON 约 600KB；上传单独 5MB |

### 文件上传过滤

| 规则 | 默认值 |
|------|--------|
| 允许类型 | **仅 `.pdf` / `.txt` / `.md`** |
| 扩展名黑名单 | exe/bat/php/html/js/zip 等 + **双扩展名伪装** |
| 魔数校验 | PDF 须 `%PDF` 开头；文本须 UTF-8、无空字节 |
| 内容扫描 | 拒绝 `<script>`、`javascript:` 等可疑片段 |
| 大小 | ≤ **5MB**（`WEB_UPLOAD_MAX_BYTES`） |
| PDF 页数 | ≤ **120 页**（`WEB_UPLOAD_MAX_PDF_PAGES`） |
| 库内文件数 | ≤ **300**（`WEB_UPLOAD_MAX_FILES`） |

公网默认 **`WEB_ALLOW_UPLOAD=1`**，上传须通过扩展名/魔数/内容过滤；若需完全禁止上传设 `WEB_ALLOW_UPLOAD=0`。

本地开发（127.0.0.1、未设 `WEB_AUTH_REQUIRED`）默认不要求令牌。  
强制开启：`.env` 中 `WEB_AUTH_REQUIRED=1` + `WEB_ACCESS_TOKEN=强密码`。

### 为什么隧道窗口看不到「使用情况」？

菜单 **16** 实际启动了两个进程：

| 进程 | 窗口里显示什么 |
|------|----------------|
| **cloudflared**（你截图里的） | 仅隧道连通性：`precheck complete`、HTTP/2 探测等 |
| **Web 服务**（后台子进程） | 对话、API 访问日志（原先不显示在此窗口） |

因此：**Cloudflare 隧道本身不会列出「谁问了什么问题」**；DeepSeek API 用量也只在 [DeepSeek 控制台](https://platform.deepseek.com/) 账单里。

更新后（重新运行菜单 16）：

- 本窗口会出现 `[Web] … [访问] …`、`[Web] … [对话] …` 行，表示有人打开页面或提问
- 浏览器访问 `https://xxxx.trycloudflare.com/api/usage` 可看本会话累计请求/对话次数（重启后清零）

若分开启动：先菜单 **2** 开 Web，再菜单 **16** 只开隧道，则 Web 日志在 **Web 那个窗口**。

## 方式二：局域网访问

同一 WiFi / 校园网内其他人访问：

1. 运行 `scripts\start_web_public.bat`（或 `.env` 设 `WEB_HOST=0.0.0.0`）
2. 本机 `ipconfig` 查看 IPv4（如 `192.168.1.100`）
3. 他人浏览器打开：`http://192.168.1.100:8080`
4. Windows 防火墙需放行 **8080** 端口

## 方式三：固定域名（Cloudflare 命名隧道）—— 推荐

适合：**要给出去一个永久不变、自己命名的地址**（发刊、长期演示、多人试用）。

默认的临时隧道是 Cloudflare 的 **quick tunnel**：域名随机发、隧道一重启就换（项目里已经作废过好几个
`*.trycloudflare.com`）。要固定地址只能换 **命名隧道（Named Tunnel）**：域名绑在
**你自己** Cloudflare 账号下的域名上，永久不变。

**前提**：你得有一个自己的域名。本项目 2026-11-07 已在阿里云购得 **`zebrafish-hub.top`**
（品牌名 Zebrafish Hub，注意中间有连字符），**2026-11-08 已完成接入**：

```
公网正式地址：https://zebrafish-hub.top
备用地址：    https://www.zebrafish-hub.top
```

详细过程、故障排查与踩坑记录见 [域名接入_zebrafish-hub.top.md](域名接入_zebrafish-hub.top.md)。
`.top` 首年约 ¥1–10、续费约 ¥30–50，学术可信度低于 `.org`/`.com`。
这台服务器不是我们的、它所在的域名也不是我们的，所以名字只能来自你自己的域名。

**为什么这条不需要服务器权限**：命名隧道依然是**服务器主动往外连**，不开任何入站端口、
不改防火墙、不需要 root —— 正好适合“服务器不是自己的”这种情况。

### 一次性准备

1. 买域名，把 **NS 改到 Cloudflare**（免费版即可），等 Zone 状态变 **Active**（几分钟到几小时）；
2. 本机跑一次（会开浏览器，**只需一次**）：

   ```powershell
   .venv\Scripts\python.exe -X utf8 scripts\setup_named_tunnel.py --hostname zebrafish-hub.top
   ```

脚本会依次完成：本机 cloudflared 就绪 → 浏览器授权 → 建隧道 `zebrafish-hub` → 绑定
`zebrafish-hub.top`（根域名，同时自动绑 `www`）→ 渲染 `config.yml` 上传服务器 → 起隧道 → **公网实测** `/api/health`。

### 切换原理（不用手工改开关）

| 服务器上是否存在 `<RT>/cloudflared/config.yml` | 隧道模式 | 域名 |
| --- | --- | --- |
| 不存在 | quick（快速隧道） | 随机 `*.trycloudflare.com`，重启就换 |
| 存在 | **named（命名隧道）** | **固定**，取自 config.yml 的 `hostname:` |

`hub_guard.sh` 由 systemd 定时器每 60 秒跑一次，**放上/删掉这个文件就自动切换**，不用重启守护。
（2026-11-07 修：旧版其实只在"没有隧道进程"时才动手，放上配置根本不会切换；现在改为从进程命令行反推实际模式，不一致就重启对齐。命名隧道连续 2 次起不来会自动回退快速隧道，宁可地址变了也不让站点失联。）

> `--revert` 以前是"假回退"（只删配置、不停进程），现已改为：停掉命名隧道进程 → 配置改名留档 → 立刻用快速隧道重新拉起并回报新地址。

### 常用命令

```powershell
# 看当前是哪种模式、域名是什么
.venv\Scripts\python.exe -X utf8 scripts\setup_named_tunnel.py --status

# 退回快速隧道（随机域名）
.venv\Scripts\python.exe -X utf8 scripts\setup_named_tunnel.py --revert
```

### 顺手修掉的一个隐患

cloudflared 二进制原来放在 `/tmp/cloudflared_run`，**服务器一重启就被清掉**，
守护会一直报 `missing_binary`、公网静默失效。现已迁到持久目录 `<RT>/bin/cloudflared_run`
（守护优先用它，找不到才回退旧路径）。

### 安全加固（固定域名之后建议做）

| 层级 | 做法 | 效果 |
| --- | --- | --- |
| 站内 | `.env` 设 `WEB_AUTH_REQUIRED=1` + `WEB_ACCESS_TOKEN=强密码` | 没令牌看不到数据 |
| 站外（更强） | Cloudflare 控制台 → Access → 给该域名加邮箱验证码 / Google 登录（免费 50 人） | 白名单外连页面都打不开 |

> ⚠️ 云端限制：Cloudflare 免费版对单个请求约 **100 秒**即返回 524，而单次问答要 **50~70 秒**，
> 余量不大；若要支持多人同时提问，应改成「立即返回任务号 + 前端轮询结果」。

## 方式四：云服务器长期对外（发刊/正式演示）

适合：长期稳定、自定义域名、HTTPS。

1. 租用 GPU 云服务器（见 `docs/服务器部署与发刊指南.md`）
2. 上传项目，`.env` 设置：

   ```env
   WEB_HOST=0.0.0.0
   WEB_PORT=8080
   MYSQL_HOST=<RDS 内网地址>
   ```

3. 启动：`python -m api.api_server`（建议 systemd 守护）
4. Nginx + SSL：参考 `deploy/nginx/zebrafish.conf`
5. 安全组放行 **443**（HTTPS），**不要**直接暴露 8080 到公网
