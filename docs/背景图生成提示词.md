# 首页背景图 · 生成提示词包

> 用途：把原素材 `斑马鱼背景图.jpeg` 的**风格与构图要求**完整翻译成提示词，
> 直接投喂给专业生图工具（即梦 / 豆包 / 通义万相 / 文心一格 / Midjourney / Flux / DALL·E / SDXL），
> 生成一张**完整、无磨砂面板**的等价背景图。
>
> 生成后跑一条命令即可上线（自动裁切、调色、升版本号、推送）：
> ```bash
> .venv\Scripts\python.exe -X utf8 scripts\apply_home_bg.py --src 你的图.png
> ```

## 一、原图特征拆解（提示词的依据）

| 维度 | 原图特征 | 必须保留的原因 |
| --- | --- | --- |
| **构图** | 水面在顶部，中间是**大片开阔水体**，左右两侧被水草/岩石框住，底部是沙床 | 首页中间放大白卡，中央必须留白干净 |
| **色调** | 极高调：接近白 → 浅天青 → 淡蓝，饱和度低，没有深色块 | 与站点 `--p-*` 浅色主题一致，正文深色字才压得住 |
| **光** | 顶部水面透下来的柔光光束，向下扩散并逐渐淡出 | 提供纵向层次，避免"一块平色" |
| **水草** | 左右两侧成簇：细长叶为主 + 少量阔叶；深绿→嫩绿渐变 | 画面的主要细节来源，也是"像不像"的关键 |
| **岩石** | 圆润灰白石头压在左右下角 | 给两侧收边，避免水草"飘" |
| **沙床** | 底部浅米色/浅灰沙，颗粒细腻 | 落地感 |
| **斑马鱼** | 3–5 条小鱼，蓝白**横向**条纹 | 主题锚点（注意是横向，不是竖向） |
| **DNA** | 右上角半透明浅蓝双螺旋装饰 | 科研属性 |
| **质感** | 水彩 + 轻插画，柔和、无明显描边 | 与品牌卡片的扁平风格协调 |
| **负面** | 原图中央那块**半透明白色磨砂面板**是"文字占位框" | **新图绝对不能有**，这是本次换图的核心目的 |

## 四、三条可选风格路线

| 路线 | 一句话描述 | 适合 |
| --- | --- | --- |
| **A. 浅蓝水彩插画**（推荐，最接近原图） | 上面两段提示词原样使用 | 与现有白卡 + 扁平图标最协调 |
| **B. 扁平矢量** | 追加 `flat vector, minimal, geometric shapes, soft shadows, no texture` | 更现代、更"产品感"，但会失去水彩的柔和 |
| **C. 真实水下摄影** | 追加 `realistic underwater photography, shallow depth of field, natural light` | 质感最好，但和现有浅色主题反差较大 |

> 已经内置了 C 路线的成品：`scripts/make_home_bg_photo.py`（Wikimedia Commons 真实水下照片，
> 构图同为"顶部水面 + 中间开阔 + 两侧水草"，CC BY 3.0 需署名）。A/B 走生图工具。

## 五、验收清单（拿到图先自查）

- [ ] 中央大片区域是**干净的水体**，没有任何矩形/圆角面板、白框、半透明遮罩
- [ ] 全身通透明亮，**没有深色大块**，把白卡放上去不脏
- [ ] 左右两侧有水草（这是"像不像"的关键），底部有沙床
- [ ] 顶部有光束/水面，纵向有层次
- [ ] 有斑马鱼（横向条纹）与 DNA 元素
- [ ] 没有任何文字/水印/签名
- [ ] 分辨率 ≥ 2048 宽

## 六、生成完怎么上线

```bash
# 一条命令：按 16:10 裁切 → 可选轻微调色 → 覆盖线上背景 → 自动升 ?v= → 推送服务器
.venv\Scripts\python.exe -X utf8 scripts\apply_home_bg.py --src "D:\下载\bg.png"

# 只本地出图不上线
.venv\Scripts\python.exe -X utf8 scripts\apply_home_bg.py --src bg.png --no-push

# 顺便压暗/提亮（默认 1.06 提亮，贴近高调）
.venv\Scripts\python.exe -X utf8 scripts\apply_home_bg.py --src bg.png --brightness 1.02 --saturation 0.95
```
