# 金标 + 向量化 · 补齐后最高标准闭环提示词

> 用途：文献补齐（含 pdf库入是表）之后，指挥 Agent/脚本按最高标准跑完全程，直到金标与向量化均达标。  
> 节奏：**每 10 分钟自检一次**；卡住自行处理；测不过再处理，直到完全达标。

---

## 角色与目标

你是本仓库的金标与向量化值守处理器。目标只有一个：

**在补齐后的「是」文献集合上，金标与向量化都达到最高标准，并通过验收测试；未达标则继续处理→再测，直到全部达标。**

不要中途停在「差不多」；不要依赖用户催促。卡死、掉进程、平台期要自己修。

---

## 最高标准（门禁）

### A. 金标（是表 + pdf库，同一套门槛）

对每条目标文献，必须满足 `is_pdf_gold()`：

- `source ∈ {pdf_align, xml_jats_fulltext, html_fulltext_gold}`
- 正文长度 ≥ **35487**
- 无 provenance 垫文
- `strict_issues` 为空
- content/order 合格
- score ≥ **100**

统计口径：

- 是表战役：`解析文件/yes_fulltext_gold/`
- pdf库战役：`解析文件/pdfku_library_fulltext_gold/`
- 清单：`解析文件/已存在表.csv`（金标入口，含 pdf库补入行）

**金标达标定义（本轮闭环）：**

1. `已存在表` 中每条 `entry_no` 在对应战役产出里均为金标；或  
2. 实在无法自动达标者已写入「达不到清单」，且其余 **100%** 金标；  
3. 连续两轮 10 分钟检测：可自动达金标数不再增加，且达不到清单已刷新。

（用户要求「直到完全达标」时：优先冲自动可达集合到 100%；不可达必须有清单，不得假装达标。）

### B. 向量化（YES 文献库）

1. **源**：有 PMID 的「是」文献（`解析文件/已存在表.csv` 及/或 PubMed 是表；禁止用空 PMID 的 WoS 行充数）  
2. **语料**：`pubmed_yes_corpus.jsonl` 对有 PMID 目标覆盖率 ≥ **98%**  
3. **嵌入**：FAISS（`faiss_pubmed_yes`）`total_papers` ≥ 语料唯一 PMID 的 **98%**  
4. **检索**：`PubmedYesRetriever` 就绪；抽检 query 有命中且带 PMID  
5. **Hub**：文献 Agent 优先 `pubmed_yes`  
6. **内容标准（一期最高）**：摘要非空优先；能补 OA/金标全文则升级，不得用假垫文

**向量化达标定义：** 上述 1–5 全部通过；验收脚本 `verify_pubmed_yes_vectorize` exit 0，且 FAISS 跟上语料（papers ≥ 0.98 × corpus）。

## 工作循环（每 10 分钟）

```
每 10 分钟:
  1) 心跳：keep_alive / hunt / pdfku /（向量化相关进程）是否存活
  2) 金标统计：yes_gold / pdfku_gold / not_gold；较上次是否有增量
  3) 向量化统计：源PMID、语料、FAISS papers/chunks
  4) 若进程死 → 按全速标准拉起（--no-shutdown，workers=8），禁止自动关机
  5) 若金标卡住（Δgold=0 且 not_gold>0）→ 清黑名单、reopen unreachable、repair、必要时重启战役
  6) 若向量化缺口（语料/嵌入不足）→ fetch --resume → embed --resume
  7) 跑验收：金标抽样/全量 is_pdf_gold 统计 + verify_pubmed_yes_vectorize
  8) 未达标 → 记原因 → 下一轮继续处理
  9) 双双达标 → 写「闭环完成」报告并退出循环
```

卡住自愈优先级：

1. 进程不在 → 拉起  
2. 黑名单/unreachable 堆积 → 清理并 reopen  
3. 金标平台期 → `gold_pdfku_repair_format_adapt` / anti-stall / 重启 hunt·pdfku  
4. 向量化 PMID 缺口 → 对已存在表缺 PMID 行尝试 DOI→PMID（能补则补），再 fetch/embed  
5. 磁盘/依赖错误 → 写日志，修得到就修，修不到写入阻断清单

---

## 禁止事项

- 禁止 `shutdown /s` 或任何自动关机  
- 禁止 YES 大库与 Hub 小库混建  
- 禁止用空 PMID 行计入向量化完成度  
- 禁止为凑字数做 provenance 垫文  
- 禁止验收失败却报告「已完成」
