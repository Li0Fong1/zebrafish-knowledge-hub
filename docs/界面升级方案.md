# 界面升级方案（简单 + 高级）

> 2026-10-10。目标：在**现有结构不变**的前提下，用「少而准」的视觉改动把观感从"能用"提到"专业"。
> 原则：**不加装饰、不加动画、不加颜色**，只做层级、间距、对齐、状态四件事。

## 0. 现状诊断（为什么现在显得糙）

| 现象 | 根因 | 证据 |
| --- | --- | --- |
| 页面"散" | 三套样式表（style / simplify / refine）各自定义令牌，首页原本用绿色 `#1f9d55`，与全站青绿 `--accent #0E7C6B` 打架 | 已在 `home-2026.css` 统一为令牌 |
| 卡片"平" | 只有 1px 边框，没有高度差；hover 无反馈 | `--shadow-1/2` 已定义但首页没用 |
| 层次弱 | 字号档位太近（12/12.5/13/13.5），权重只有 400/600 | 首页已引入 12 / 13.5 / 15 / 17 / clamp(26-38) |
| 控件"各自为政" | 输入框/按钮/下拉圆角与高度不统一 | 首页已统一为胶囊 + 38px 高 |
| 焦点不可见 | 缺 `:focus-visible` 样式 | 首页已加（含 `focus-within` 光圈） |

## 1. 设计基调（一页定死，后续所有页面照此执行）

**1.1 令牌（沿用 refine.css，不再新增颜色）**

| 用途 | 令牌 | 值 |
| --- | --- | --- |
| 页面底 / 卡片底 / 次级底 | `--bg` / `--panel` / `--panel-2` | `#F9FAFB` / `#FFF` / `#F4F6F8` |
| 分隔线 / 强调分隔 | `--line` / `--line-strong` | `#E7EAEE` / `#D7DCE3` |
| 正文 / 次要 / 三级 | `--ink` / `--ink-2` / `--ink-3` | `#0B1220` / `#4B5563` / `#667085` |
| 唯一强调色 | `--accent` / `--accent-ink` / `--accent-weak` | `#0E7C6B` / `#0A5F52` / `#EAF4F1` |
| 圆角 | `--radius-sm/--radius/--radius-lg` | 8 / 12 / 16 |
| 阴影 | `--shadow-1` / `--shadow-2` | 静止 / 悬浮 |

**1.2 字号档位（5 档，不再新增）**：12（元信息）· 13.5（辅助）· 15（正文）· 17（卡片标题）· 26–38（页面主标题）。
**1.3 间距节奏（8 的倍数）**：组件内 8/12，区块内 16/20，区块间 28/40。**同类元素间距必须一致**。
**1.4 交互三态**：hover（描边→accent + 底色 `--accent-weak`）、focus-visible（2px accent 光圈）、disabled（opacity .55 + `cursor: default`）。
**1.5 动效预算**：只允许 opacity/transform 的 ≤180ms 过渡；**不加位移动画、不加循环动画**（共享服务器，省 CPU/GPU）；`prefers-reduced-motion` 下一律关闭。

## 3. 验收标准（可量化，避免"感觉好看了"）

1. **对比度**：正文 ≥ 7:1，二级文字 ≥ 4.5:1（`--ink-3 #667085` 在白底 5.1:1，达标）。
2. **字号档位**：全站出现过的字号种类 ≤ 8 种（现状首页 5 种）。
3. **间距一致性**：同类列表项的内边距全部来自同一变量（抽查 10 处）。
4. **无新增动画**：`grep -E "@keyframes|animation:" web/css/*.css` 结果不增加。
5. **键盘可达**：Tab 遍历首页，每个可点元素均有可见焦点环。
6. **深浅色**：两套主题各截 4 张图（Home / Chat / Tools / Literature），无低对比文字。

## 5. 明确不做（避免"越改越花"）

- 不加背景动效/粒子/波浪（已删过一轮，共享机 CPU 敏感）。
- 不引入 UI 框架或图标库（多一个依赖 = 多一份首屏体积与离线风险）。
- 不加多于一个强调色；不为了"满"而填内容（宁可留白）。
- 不改信息架构与路由（`#/home`、`#/chat`… 保持不变，论文与文档里的链接不受影响）。

## 6. 首页收敛记录（两次，可回溯）

| 轮次 | 动作 | 理由 |
| --- | --- |
| 第一轮（P0） | 令牌化配色（弃用 `#1f9d55` 绿）、干掉 599px 的 `min-height`（原先把「今日研究」挤出首屏）、胶囊搜索条 + `:focus-within` 光圈、今日研究卡左 3px 强调条、更新列表时间线、语言按钮自适应宽度 | 先修"错"（对比度/首屏/焦点）再谈好看 |
| 第二轮（P0+） | 见上表；**净效果：首屏少 1 个 chip、少 1 整行留白、更新列表少 2 条**，视觉重心从"块块分隔"移回"标题 + 搜索" | 用户原话「更简单高级一些」＝减元素 + 拉开层级，不是加装饰 |
| 唯一强调色规则 | 全页强调色只出现在：搜索按钮、链接、今日研究左条、Cite Us 左边框；徽标底色统一 `--accent-weak`（不再各自调色） | 避免"到处都亮"＝廉价感 |
