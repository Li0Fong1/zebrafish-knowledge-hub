\section*{DATA AND CODE AVAILABILITY}

The code for the Zebrafish Knowledge Hub (agent orchestration, retrieval and
packing pipeline, web front-end and deployment scripts) is hosted on Gitee
(\tbd{TODO: repo\_url}). Benchmark questions, manually curated reference answers,
blinded judge inputs and raw model outputs, scoring tables and the exact
permutation-test results are available on Figshare
(\tbd{TODO: data\_deposit}). Reference annotations were downloaded from Ensembl
(GRCz11, release 116; \url{https://www.ensembl.org/}), NCBI RefSeq (GRCz12tu,
GCF\_049306965.1; \url{https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_049306965.1/}),
ZFIN (\url{https://zfin.org/}), Bgee (v15.2; \url{https://www.bgee.org/}) and the
EBI Expression Atlas (E-ERAD-475; \url{https://www.ebi.ac.uk/gxa/}), and literature
records were retrieved from PubMed (\url{https://pubmed.ncbi.nlm.nih.gov/}) and
Europe PMC (\url{https://europepmc.org/}).

\section*{ACKNOWLEDGMENTS}

We acknowledge the computing resources of Hunan Normal University used for index
construction and model serving, and we thank the researchers who tested the
platform for performance and stability and provided constructive feedback. No
conflict of interest is declared.

\section*{AUTHOR CONTRIBUTIONS}

Kaifeng Qu conceived the study; developed the code of the Zebrafish Knowledge Hub
(agent orchestration framework, web front-end and back-end, initial creation of the
relational database, full-text parsing, and the vectorisation and retrieval
pipeline); performed the performance evaluation; and wrote the manuscript with the
assistance of AI coding environments as declared in section~2.6. \tbd{Author B}
collected and curated the omics annotation data (gene coordinates, expression, GO
and pathway annotations). All authors read and approved the final version.
