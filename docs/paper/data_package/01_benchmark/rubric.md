#评分细则（7 维，满分 10）

- 盲评口径：每维 0=差 1=中 满分=好；两系统同题对照
- 维度数：7；满分：10

| 维度 ID | 名称 | 满分 |
| --- | --- | --- |
| `direct_first` | 第一句直接答完 | 2 |
| `factor_structure` | 按因素/机制组织而非论文章节 | 2 |
| `ge_formula` | 性状题出现 G+E 或等价表述 | 1 |
| `inline_cite` | 正文 [n] 与文末参考文献对应 | 2 |
| `ref_count` | 相关参考文献数量适中(约8-15) | 1 |
| `recency` | 近年文献可见、不无故堆经典 | 1 |
| `no_review_shell` | 无综述腔/无关章节 | 1 |

> 本文件由 `scripts/build_figshare_package.py` 从基准题 JSON 派生（仅格式转换）。
